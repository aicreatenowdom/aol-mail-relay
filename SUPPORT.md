# AOL Mail Relay System support

For product help, delivery questions, or activation support, email [info@aicreatenow.com](mailto:info@aicreatenow.com) or call **1-866-315-4750**.

Include the product name, application version, Windows version, a short description of the issue, and the steps that reproduce it. For purchase or delivery questions, include the checkout email address in your private message.

Do not post passwords, AOL app passwords, API tokens, license keys, or unredacted logs in public issues. Share any necessary diagnostic information privately with support.

Current download, purchase, requirements, and delivery details are on the [official product page](https://aicreatenow.com/aolrelay.html).

This repository provides product documentation. The application is proprietary and its source code is not included.

GitHub's **Code → Download ZIP** downloads this repository's documentation and artwork. Use the official product page linked above to obtain the application.

## Before contacting support

- Check whether the message arrived in the Inbox after forwarding was activated and whether Windows was awake for the scheduled check.
- Include the relevant dashboard status and log error, with mailbox addresses and message content redacted where unnecessary.
